Victor Cardoso — Portfolio

Personal portfolio website for **Victor Cardoso**, Front-End Developer based in Brazil. Built from scratch with pure HTML, CSS and JavaScript — no frameworks, no build step.


Features

- **Bilingual (EN / PT-BR)** — instant language switch via a single toggle, no page reload
- **Light / Dark theme** — toggle with preference saved in `localStorage`
- **Fully responsive** — adapts down to mobile, with a collapsible nav menu
- **Scroll-aware navigation** — active section highlighted automatically using `IntersectionObserver`
- **Smooth micro-interactions** — hover states, transitions, and a subtle scroll hint on the hero section

Built with

- **HTML5** — semantic structure
- **CSS3** — custom properties (CSS variables), Flexbox & Grid, responsive media queries
- **JavaScript (Vanilla)** — DOM manipulation, `IntersectionObserver`, `localStorage`
- [Font Awesome](https://fontawesome.com/) — icons
- [Google Fonts](https://fonts.google.com/) — Inter & Fraunces

Project structure

```
├── index.html      # Markup
├── style.css       # All styling
├── script.js       # Theme toggle, language toggle, nav & mobile menu logic
└── cv/
    └── Victor-Cardoso.2026EN.pdf   # Downloadable CV
```

Running locally

No build tools or dependencies required. Just clone and open:

```bash
git clone https://github.com/v1ctorx/your-repo-name.git
cd your-repo-name
```

Then open `index.html` directly in your browser, or serve it locally:

```bash
npx serve .
```
